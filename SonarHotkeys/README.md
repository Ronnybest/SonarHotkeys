# SonarHotkeys

Приложение для переключения пресетов Game и физических устройств вывода в SteelSeries Sonar.

1. Запустите SteelSeries GG и включите Sonar. Пресеты должны быть отмечены как избранные в GG.
2. Запустите SonarHotkeys и нажмите «Обновить из Sonar».
3. В строке The Witcher 3 выберите колонки, в строке War Thunder * — наушники.
4. Нажмите сочетание в ячейке таблицы и нажмите «Сохранить». Delete очищает назначение.

Начальные сочетания: Ctrl+Alt+1 — The Witcher 3, Ctrl+Alt+2 — War Thunder *, Ctrl+Alt+F12 — следующий настроенный избранный пресет. Устройства нужно выбрать один раз: начальное значение «Не менять устройство».

Перебор идёт в порядке строк таблицы и учитывает текущий пресет в GG. Пресеты, удалённые из избранного или Sonar, пропускаются. Меню в трее показывает настроенные избранные пресеты; при переключении используется и сохранённое устройство.

В Classic устройство меняется для Game, Chat, Media и Aux. В Streamer меняется выход Personal. Пресет меняется только для Game. При ошибке после частичного переключения приложение пытается восстановить предыдущие настройки и сообщает результат.

Настройки хранятся в `%LOCALAPPDATA%\SonarHotkeys\settings.json`. Изменения таблицы вступают в силу после сохранения; конфликт сочетаний или ошибка записи оставляет предыдущую конфигурацию активной. Повреждённый файл не перезаписывается автоматически: восстановленные начальные значения можно сохранить вручную.

Закрытие окна скрывает приложение в трей. Двойной щелчок или «Настройки» открывает окно; «Выход» завершает программу. Аргумент `--tray` скрывает окно при запуске. Вторая копия приложения сразу завершается. Уведомления показывают выбранный пресет, устройство или причину ошибки; щелчок по уведомлению открывает окно с полным сообщением. Windows может скрывать уведомления своими настройками.

Сборка: `dotnet build -c Release` (.NET 10 SDK). Публикация самостоятельного EXE: `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish`.
